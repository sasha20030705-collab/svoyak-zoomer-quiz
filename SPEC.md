# Квиз «Своя игра» на день рождения — спецификация

## Что хочет заказчица (из голосовых)
- Формат как у Коваля «СВОЯК» (https://www.youtube.com/watch?v=5RK0YnF2U6s) — «Своя игра»: табло, темы × номиналы 100/200/300/400/500.
- Команда выбирает ячейку (тема + стоимость). Чем дороже — тем сложнее.
- Кто из команд первым ответил правильно — получает баллы. Неправильно — минус, ход/право ответа переходит другой команде.
- Темы зумерские, актуальные (2024–2026), весёлые, местами сложные. НЕ Киркоров/Басков — скучно.
- Пример темы «Слияние звёзд»: ИИ-скрещённые лица двух звёзд (Charli XCX + Addison Rae), угадать обоих. Звёзды уровня: Charli XCX, Addison Rae, Adele, Lana Del Rey, Evan Peters.
- Также «корейская» тема и вайб «Где логика?» (Нурлан Сабуров, Азамат Мусагалиев) — русские ТНТ/стендап/интернет-знаменитости.
- Без пошлостей.
- День рождения — 21 октября 2026.

## Техника
- Чистый HTML/CSS/JS, без сборки, без фреймворков (можно подключить с CDN canvas-confetti, но лучше всё локально/inline — квиз должен работать офлайн).
- Запуск: `start.command` поднимает `python3 -m http.server 8777` в папке и открывает браузер.
- Два экрана, синхронизация через `BroadcastChannel('quiz')` + состояние в `localStorage` (переживает перезагрузку):
  - `index.html` — **пульт ведущего (организатора)**: создание команд (название, цвет, эмодзи), запуск игры, выбор ячейки, видит правильный ответ, кнопки «Верно +N / Неверно −N» для каждой команды, таймер, откат последнего действия (undo), правка счёта вручную, переход между раундами, финал.
  - `screen.html` — **экран для гостей** (на ТВ/проектор, fullscreen): табло, вопрос с медиа, анимации, счёт команд, без ответов пока ведущий не нажмёт «Показать ответ».
- Баззер: на экране гостей каждая команда может «нажать» своей клавишей (Q, P, Z, M, …) — фиксируется кто первый, с анимацией и звуком. Ведущий может сбросить.

## Формат данных — `data/questions.js`
```js
window.QUIZ = {
  title: "…",
  rounds: [
    {
      name: "Раунд 1",
      multiplier: 1,
      categories: [
        {
          name: "Слияние звёзд",
          emoji: "🧬",
          description: "Нейросеть скрестила двух звёзд. Назовите обоих.",
          questions: [
            {
              value: 100,
              type: "fusion",            // text | image | fusion | zoom | emoji | blur
              special: null,             // null | "cat" (кот в мешке: передать другой команде) | "auction" (ставка)
              prompt: "Кто здесь смешался?",
              media: { images: ["assets/img/charli-xcx.jpg", "assets/img/addison-rae.jpg"], fused: "assets/fusion/charli-addison.jpg" },
              answer: "Charli XCX + Addison Rae",
              note: "Вместе записали ремикс Von dutch / тур «Brat»…"   // факт-комментарий для ведущего и показа после ответа
            }
          ]
        }
      ]
    }
  ],
  final: { category: "…", prompt: "…", media: {…}, answer: "…", note: "…" }
};
```
Типы:
- `text` — просто текст вопроса.
- `image` — одна или несколько картинок `media.images`.
- `fusion` — `media.images` = 2 фото звёзд; если есть `media.fused` (готовое ИИ-слияние) — показывается оно, иначе экран сам делает «слияние» наложением двух фото (50/50 прозрачность, mix-blend, подогнано по центру лица) с эффектом глитча; после ответа — раздвигаются в два оригинала.
- `zoom` — `media.images[0]`, стартует с сильным зумом (`media.zoom` = {x:0.5,y:0.3,scale:6} точка фокуса) и постепенно отдаляется по таймеру.
- `blur` — фото сильно размыто, по таймеру проясняется.
- `emoji` — `media.emoji: "🧛‍♂️🌒💍"` крупно.

Пути картинок: `assets/img/<slug>.jpg` (slug латиницей, kebab-case). Список нужных картинок — `data/images-needed.json`: `[{ "slug": "evan-peters", "query": "Evan Peters", "wiki": "Evan_Peters" }]`.
